# 🇮🇳 StickerBridge: Hindi / Hinglish Guide

Telegram ke stickers ko WhatsApp mein use karne ka sabse aasaan tareeka.

---

## 📥 1. App install karo

1. Phone mein ye link dabao: **[⬇️ StickerBridge.apk download karo](https://github.com/J4XD/StickerBridg/releases/latest/download/StickerBridge.apk)**
   APK seedha download ho jayegi.
2. Download pura hone ka wait karo. Chrome "file harmful ho sakti hai" bole to **Download anyway** dabao.
3. File kholo. Agar phone poochhe *"Install unknown apps"*, to **Allow** karo.
4. **Install** dabao. ✅

---

## 🔑 2. Bot token lo (sirf pehli baar, 30 second ka kaam)

1. Telegram kholo aur search karo **@BotFather**. Blue tick ✔️ wala hi chuno.
2. Usko `/newbot` bhejo.
3. Koi bhi naam bhejo, jaise: `Mera Sticker Bot`
4. Ab ek username bhejo jo **`bot` pe khatam ho**, jaise: `mysticker12345_bot`
5. BotFather aapko ek token dega, kuch aisa:
   ```
   7012345678:AAH1bCdEfGhIjKlMnOpQrStUvWxYz123456
   ```
6. Poora token copy karo aur StickerBridge mein **"Telegram bot token"** wale box mein paste karo.

> 💡 **Token kyun chahiye?** Telegram sticker files sirf apne official Bot API se download karne deta hai.
> Purane apps sabke liye ek hi token use karte the. Telegram ne woh token block kar diya, isliye woh apps band ho gaye.
> Aapka apna token hoga to ye app kabhi band nahi hoga.
>
> 🔒 **Safe hai?** Haan. Ye token aapke messages nahi padh sakta. Ye sirf us khaali bot ka hai jo aapne banaya.

---

## 🔗 3. Sticker pack ka link copy karo

Telegram mein koi bhi sticker pack kholo, upar **⋮** dabao, fir **Copy link**.

Link aisa dikhega: `https://t.me/addstickers/PackKaNaam`

⚡ **Shortcut:** **Copy link** ki jagah **Share** dabao aur **StickerBridge** chuno. Link apne aap aa jayega.

---

## ⬇️ 4. Import karo

Link paste karo aur **Import pack** dabao. Progress bar dikhega. Bade pack mein 1-2 minute lag sakte hain.

---

## ✅ 5. WhatsApp mein add karo

1. Pack ke neeche **Add to WhatsApp** dabao.
2. WhatsApp khulega aur poochega *"Add sticker pack?"*. Wahan **Add** dabao.
3. Ho gaya! 🎉 WhatsApp chat mein 😀 button dabao, fir sticker tab mein aapke stickers dikhenge.

---

## 📌 Zaroori baatein

| Baat | Matlab |
|---|---|
| **30 se zyada stickers** | WhatsApp ek pack mein 30 tak hi leta hai, isliye bada pack 2-4 hisson mein banega. Har hissa alag se add karo. |
| **Normal + animated** | Dono alag packs mein aayenge (WhatsApp ka rule hai). |
| **Video stickers** | *"Include video stickers"* tick karo. Background kaala ho sakta hai. |
| **App delete mat karna** | WhatsApp stickers isi app se leta hai. App hataoge to stickers bhi hat jayenge. |

---

## 🛠️ Problem aaye to

| Problem | Kya karein |
|---|---|
| `Bot token is invalid` | @BotFather se token dobara poora copy karo |
| `Sticker pack not found` | Link check karo, shayad pack delete ho gaya |
| WhatsApp bole *"problem with this sticker pack"* | WhatsApp update karo, pack delete karke dobara import karo |
| Network error | Internet check karo, Wi-Fi ki jagah mobile data try karo |

Fir bhi problem ho to **[yahan issue kholo](https://github.com/J4XD/StickerBridg/issues/new/choose)** aur screenshot daalo. 🙏
